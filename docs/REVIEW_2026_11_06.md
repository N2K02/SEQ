# SEQ focused code and UI review — 2026-11-06

Scope: one experimental PR, no new screens or menus. Compared source layout with mRadio and platform guidance.

## Implemented corrections
- **ADB lifecycle:** Worker waits for verified session or timeout, cancels child tasks, awaits cleanup with a deadline, and releases its own controller. Accessibility-only discovery expires after 90 seconds when Diagnostics is not open. Quit cancels OS recovery.
- **Safer default ADB behavior:** automatic local discovery stays enabled, but boot/watchdog jobs and TCP/5555 promotion require explicit opt-in on new installations. Existing saved choices remain unchanged.
- **Music list:** show 20 tracks initially, with a compact Show more action. Avoids eager composition of hundreds of rows in a vertically scrolling host. No nested LazyColumn.
- **Settings retention:** retain selected page across configuration changes.
- **Native PCM:** signal settings generation only on writes; native DSP rebuilds at most once per 250 ms during editing and crossfades over 128 frames. No preference reads or UI polling for unchanged PCM blocks. Pure remains a bypass.
- **Session ownership:** do not attach platform Equalizer to SEQ's own Media3 audio session on top of its native DSP; avoid broadcasts without the mandatory source package field.
- **Tests:** JVM contract and pure logic tests for ADB shutdown, opt-in defaults, music batching, revision updates, and session exclusion.

## Unverified / intentionally unchanged
- Actual Android Auto discovery, USB BIT_PERFECT routing, audio latency, peak-guard conformance, energy use and acoustic quality require device measurements. Do not claim universal third-party audio effect attachment or certified true-peak limiting.
- Debug APK signing is not a stable update identity; a persistent release signing key is required for reliable in-place upgrades.
- No new navigation, persistent audio analyzers, waveform animations or background polling was introduced.
